## 第一批结论（opus，`claude -p` 走订阅，只能看方向）

- **思考深度影响大**（`results/batch1-depth.md`）：固定局面题，stateless，两种棋各 30 个局面 × 四档 × 2 遍，每格 60 次作答，共 480 次。
  - 中国象棋大失误率 medium 20% / high 22% / xhigh 5% / max 3%；「谁能吃到谁」类 30% / 27% / 13% / 0%。
  - 国际象棋（lichess 谜题）解中率 53% / 65% / 73% / 88%。
  - 同局面配对，medium→max 两种棋都没有一个局面变差（中国象棋谁能吃到谁类 11 好 0 坏，国际象棋 15 好 0 坏）。medium 和 high 分不开。
  - 代价：每次作答耗时中位 xhigh 34–75 秒、max 102–392 秒；max 花费约为 xhigh 的 4–5 倍。
- **思考延续是次要因素**（`results/batch1-carryover.md`）：effort=high，stateless / notes / session 三档。国际象棋对 Maia-1100 每档 3 盘，中国象棋对 Fairy-Stockfish nodes=100 每档 2 盘，共 15 盘。
  - 前提成立：删思考对照 37/37、6/6 对 0/6，思考能带过去，模型也用得上（design.md P5 的缺口已补）。
  - 中国象棋三档大失误率 7.7% / 6.1% / 6.8%，看不出差别；6 盘每盘前 18 个半回合都白丢一个车，5 盘被将死。
  - 国际象棋 5.9% / 2.8% / 1.8%，有带延续少犯大错的迹象，但件数只有个位数。对手是确定性的，9 盘只走出 3 条开局路线，档位差别和开局路线分不开。
- **剩下的错集中在「谁能吃到谁」和看杀**：中国象棋 xhigh / max 残余昏招 5 条全是这一类（4 条炮架、1 条走子可达），x05、x16 原样重犯上一轮。国际象棋 max 的残余错多是找不到弃子、闪击这类要多算几步的战术。
- **对用户原假设**：「每步丢思考是下得臭的根源」这批数据不支持它是主因。
