# 第二批块 A：「谁能吃到谁」和看杀（局面题）

- 日期：2026-09-26。条件：opus（服务端 `claude-opus-5-5`，`claude -p` 走订阅），xhigh，stateless，history=0，中文提示（块 0 加的「请用中文回答。」）。程序 `llmchess/quiz.py`，作答期间仓库在 97d6de5 → dc97764 之间，`llmchess/` 和 `data/` 没有变化。

- 样本：中国象棋 30 个局面（23 个 group）× 3 遍，国际象棋 21 个局面（20 个 group）× 2 遍；**每档每格 90 / 42 次作答**，四档共 528 次，全部有着法，没有判负、放弃。局面在 `data/batch2/{xiangqi,chess}.jsonl`（入库，选取规则写在同目录 `select_positions.py` 开头）。中国象棋 30 个里 14 个「谁能吃到谁」、6 个「多步战术或其他」、10 个「看杀」（第一批整盘被将死前 1–3 步、仍有不输着法的局面）；国际象棋 11 / 8 / 2。

- 原始数据在被 git 忽略的 `runs/quiz-batch2/<档>/<棋种>/`（每次作答一个文件，逐题判定 `judged.jsonl`）。本文的统计、逐条读原文、x2-25 核对都用一次性脚本，放在 scratchpad，没入库。

## 一句话结论

**这类昏招多数不是「完全没看见」，而是「看见了、判断错」：逼它把走后对方能吃、能将的着法列出来，直接吃子和将军几乎全能列对（中国象棋 220/221），昏招里「根本没列出来」的一条都没有，剩下的错全在列出以后的判断，或者反驳根本不是一步吃子、将军。提示能压下狭义的「白送子 / 漏吃」（selfcheck、threats 都够「有效方向」），但大失误总数和看杀都压不下去：错从白送子挪到了多步战术和看杀上。** 国际象棋四档都看不出差别。

## x2-25 核对

读原文时发现：选题时记下的唯一安全着相一退三（i2g0），引擎走后也像被杀。用 judge 同一引擎、同一设置（Fairy-Stockfish depth 16，Threads 1，Hash 64，带完整历史）重跑，每步两遍、结果一致：

- 走前局面引擎直接给「−8 步杀」，也就是按引擎自己的看法，这个局面怎么走都输。
- 19 个合法着法里 18 个走后是杀（1–10 步）；唯一例外 i2g0 走后给 −3500 厘兵，不是杀分，所以当初被记成「安全」。
- 换更深的 depth 20、24 复看，i2g0 走后也是杀（−8、−7）。它在 depth 16 下的「不被杀」是搜索深度不够的假象。
- 模型走过的三步：炮七进五、帅六平五走后都是 −4 步杀；相一进三走后 −8，跟走前一样长，并没有比「最佳」更差。

所以 x2-25 算不上一道看杀题，四档 12/12 的「走进杀」都应当剔除。剔除后的数字见核心表下的注和配对一节，方向不变。

顺手用 depth 20 复看其余 9 个看杀局面（只作参考，不是 judge 口径）：x2-21、x2-22 走前也被看出很长的杀（−19、−27 步），但各还有一步在 depth 20 下不被杀，模型的错是走进 1–2 步内的短杀，题仍然成立，只是标为边缘。另有 6 次作答（x2-21 的 f2e1 四次、x2-28 的 c2a1 两次）在 depth 16 下记成不输，depth 20 下是杀；如按更深口径算，各档不输率还要再低一点（base 少 2 次，selfcheck 2、threats 1、legal 1），不改变配对方向。

## 结论怎么读（对照 plan）

- **问题 1，看不见还是没当回事**：在「走后对方能不能一步吃到、将到」这一层，主要是**判断或算度问题**。threats 档昏招里「根本没列出来」为 0（中国象棋 0/18、国际象棋 0/14），列出来了还照走的占多数（10/18、9/14），其余是反驳本身不是一步吃子或将军。base 下的「没提到」多（中国象棋 17/24），但一逼它列就几乎全列得出来，说明那更像是没去查，不是查不出。真正没进视野的，集中在清单管不到的地方：一步静着形成的双击或捉子、出将借照面、起杀的第一步。
- **问题 2，提示能不能压下去**：只压得住最窄的那一类。selfcheck、threats 在中国象棋「谁能吃到谁类」上够「有效方向」，所以对白送子 / 漏吃，**提示就能补，不是只能靠加深思考**；但大失误总数、看杀、国际象棋都看不出改善，错挪到了多步战术和看杀上。legal（给合法着法清单）哪项都看不出。
- **问题 3，告诉它攻击关系后错还剩多少**：attackmap 没批、没跑，**这一问没有答案**。以下是推断，没有验证：threats 清单已经把走后一步的吃子和将军列到接近 100%，剩下的昏招是列出后判断错、或者反驳在一步吃子之外，所以直接给「现在谁能吃到谁」大概压不掉它们；它最可能帮到的是 base 下那些「没提到」的直接吃子，而这一块 threats、selfcheck 已经压下去了一大半。

## 口径与局限

- **样本少**：每格 90 / 42 次、30 / 21 个局面，同 group 局面、同局面几遍都不独立；比了三档 × 三指标 × 两种棋，个别 p≈0.03 当方向看。
- **记录里没有思考内容**：「没提到」只代表回复正文没写，不代表思考里没想过；「看见没有」「性质」都是读正文、对着引擎续着判的，个别条目可以两读（逐条说明在读原文的材料里）。
- **x2-25** 无解，见上；其余看杀局面按 depth 16 判，更深看会再少几次「不输」。
- **c2-18** 按 lichess 口径原本只是 inaccuracy（选题时误归「大失误走前局面」），照常保留；它在四档都没出过大失误，只让分母多 2 次。
