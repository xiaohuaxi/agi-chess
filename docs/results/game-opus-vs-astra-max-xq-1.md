# opus xhigh 对 astra max：中国象棋四盘，互换先后

## 一句话结论

**astra 调到 max 后，中国象棋从 xhigh 时的 0 比 4 变成 2 比 2：执红、执黑各 1 胜 1 负，四盘都是将死。** 四盘都一口气下完，0 判负、0 续跑、0 工具调用、0 故障；非法着只有 opus 2 次（一次是第一步回复里只有一行乱码没写着法，一次塞象眼），都下一次改对。astra 的下法确实干净了：每步平均亏损 177.7→71.9，大失误率（按未分胜负的步）23%→8%，每步思考中位 409→1,237 token，每步耗时 22→49 秒。但**同盘的 opus（一直是 xhigh）也一起变干净**（134.5→66.7，17%→5.5%），所以不全是 astra 变强，有一部分是这四盘对局本身没那么乱；astra 相对 opus 的差距从「亏损多三成」缩到「多一成」，比分追平，方向上支持 max 对 astra 的中国象棋有用。输赢多半还是一步漏看决定：astra 两负都是在均势下一步走进一步杀，opus 一负是车吃象时漏了另一只象能吃回。**只有 4 盘，只看方向。**

读法：
- **比分变了**：xhigh 四盘 opus 全胜，max 四盘各赢两盘。4 盘对 4 盘，这个翻转是这批里最显眼的信号，但 0 比 4 到 2 比 2 在 4 盘的偶然范围内也说得通。
- **下法质量一起变好**：astra 每步平均亏损降到四成、大失误率降到三分之一；opus 同样降到一半、三分之一。两边一起变干净，说明这四盘对局本身比 xhigh 第二轮那两盘（双方互相挂车、亏损都在 170–270）平稳，不能把 astra 的改善全记在 max 头上。**扣掉这层，astra 相对 opus 的差距从亏损多 32% 缩到多 8%，这部分方向上可以算 max 的**。
- **想得多了三倍、慢了一倍多**：astra 每步思考中位 409→1,237，是国际象棋上 max 涨幅（173→416）的一点三倍左右；每步多等 27 秒。astra 最多一步想了 7,570 token；opus 最多 21,000。
- **opus 花费**：四盘 $24.62，最贵的盘 2 下了 161 个半回合、$12.60，离单盘 $40 很远。
- **xhigh 时的共同盲点这四盘没再出现**：「车平到自己炮后面、被对方炮隔炮打」在 xhigh 四盘里出现 3 次，这四盘都走了车九平八 / 车１平２，但都没有构成送车，也没被引擎判成大失误。
- **一次怪回复**：盘 1 冒烟时 opus 第一步的回复只有两行 `<reasoning_effort>40</reasoning_effort>`、0 思考、没有着法，程序按「认不出」记 1 次非法，第二次正常走中炮。全部对局记录里第一次见到，只此一次。

## 典型昏招

### 输棋的那一步：都是没看到

- **盘 1，opus 第 23 个半回合 车四平五（0→−748）**：车吃象将军，理由把对方三种应将都列了，写「这只车在 e7，对方也没有子能吃它」；下一步 astra 用另一只象（g9）飞 e7 吃回车。opus 再下一步理由自己写「我算漏了：对方 g9 的象可以飞到 e7 吃回我的车，结果我用一车只换了一象」。**又是「谁能吃到谁」漏看象**，和第二批、xhigh 那批同一类。之后 astra 把多一车的优势一路兑现到将死。
- **盘 3，astra 第 100 个半回合 马６进８（0→被一步杀）**：均势下理由写「调马控制红帅前方，并保护卒向宫内横进的落点，准备马卒联攻」，一步走进杀。
- **盘 4，astra 第 45 个半回合 马三进一（−38→被一步杀）**：理由「跳马攻击过河卒，先调动受困的右马」，同样是均势下一步走进杀。

astra 这两盘前面下得不差（去掉最后那一步，每步平均亏损 26 / 34），就是最后一步没看到对方的杀着；xhigh 那批 astra 输掉的四盘里也有两盘是最后几步没看到杀（相三进五垫将、马九退七）。max 没把这类漏看消掉。

### 盘 2：一盘 161 个半回合的乱战（astra 胜）

- opus 在第 30–37 个半回合一度多子、领先 500–1,200 厘兵。**第 38 个半回合 炮２进５（+1173→+324）**：理由写「我的 b7 炮可以隔着红车打掉 b2 的红炮……无论哪种，我仍然保持多子」；下一步 astra 车八进四沿 b 线吃掉 opus 底线的车并将军，opus 理由写「我漏算了：红车从 b5 沿 b 线一路进到 b9，吃掉了我的车」。没看到。
- 第 41 个半回合 astra 车一进二又送回大优势（−373→−2184），opus 第 42 个半回合马４退６ 把局面走成被五步杀（引擎），astra 下一步也没走出杀着——双方一来一回都漏了杀，这两步不在大失误统计里（走前已经是「分了胜负」的局面）。
- 中段 opus 连着几步判断错：第 50 个半回合 卒７进１（亏 381）、第 52 个半回合 炮７退１（亏 689）、第 64 个半回合 炮３进２（亏 678）。理由都写得很长，列了对方的应法和自己的抽将计划，结论是「抽将是先手」「就是杀棋」，引擎不认。**看见了、算错了**。
- 第 114 个半回合 opus 将６平５（亏 346）之后进入红方双车兵对黑方车士象的残局，opus 理由写「守住就是和棋」，最后被单车将死。

### 开局里两盘一样的一对漏着

盘 1、盘 3 开局完全相同，第 6 个半回合 astra 卒７进１、第 7 个半回合 opus 马八进七都被引擎判成大失误（引擎首选车二进六，亏 338），两盘各记了一次。这是开局里引擎深度 16 的一个判断，双方两盘走法一样，记在数字里但不当典型。

## 看得出和看不出的

- 看得出：astra max 能顺畅下完中国象棋整盘（四盘 183 步，0 非法、0 工具调用、0 故障），代价是每步近 50 秒，最长一盘接近三个钟头。
- 看得出（方向）：astra 调到 max，中国象棋从 0 比 4 追到 2 比 2，相对 opus 的每步平均亏损差距从三成缩到一成；但同盘 opus 也一起变干净，改善有一部分是对局本身。
- 看得出（方向）：输赢仍主要取决于一步漏看——谁能吃到谁（opus 漏象）、走进一步杀（astra 两次）；max 没消掉这类错。
- 看不出：max 对 astra 的中国象棋到底值多少。只有 4 盘，要钉住得在同一批局面上做局面题，对比 astra xhigh 和 max 的选着。
