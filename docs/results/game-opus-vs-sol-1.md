# opus 对 sol 首局：新协议下两种棋各一盘

## 一句话结论

**新协议（模型就是真实棋手、每方整盘一个会话）第一次正式对局，两盘都是 opus 执先将死 sol；双方 0 次非法着、0 次工具调用、0 次异常，协议本身跑得很顺。** 但两边都在「谁能吃到谁」上互相送子、互相漏吃：中国象棋 opus 走车九平八把车送到对方炮口，sol 下一步没吃；国际象棋 sol 送后。**只有 2 盘，只能看个样子，不能拿来比棋力。**

## 条件

| 项 | 取值 |
|---|---|
| 棋手 | 先手 `claude:opus`（服务端 claude-opus-5-5），后手 `codex:sol`（gpt-6-sol）；都走 llm-chat，双方都显式传 `--effort xhigh` |
| 协议 | `--protocol real`（默认，`design.md` 第九节）；memory=session，每方整盘一个会话；默认给法（中国象棋只给子力清单，国际象棋 FEN + 字母棋盘）；非法每步最多 4 次、用完判负；上限 200 个半回合 |
| 开局 | 标准初始局面，不用随机开局 |
| 命令 | `python3 -m llmchess play --game xiangqi --red claude:opus --black codex:sol --effort xhigh --tag g1-x-opus-sol`；国际象棋同理（`--white`，`--tag g1-c-opus-sol`） |
| 程序 | 下棋用 commit 7e9f0e6；棋谱用 9e0c875 的 `export` 重新导出（带每步元信息） |
| 事后裁判 | 国际象棋 Stockfish 19 深度 18（大失误按 lichess 口径），中国象棋 Fairy-Stockfish 深度 16（单步亏 ≥250 厘兵算大失误，100–250 算失误）；只数未分胜负的步 |
| 原始数据 | `runs/g1-x-opus-sol/`、`runs/g1-c-opus-sol/`（被 git 忽略，只在本机）；棋谱 `runs/g1-x-opus-sol/record.txt`、`runs/g1-c-opus-sol/game.pgn` 和 `record.txt` |

## 结果

| 项 | 中国象棋 | 国际象棋 |
|---|---|---|
| 结果 | 红（opus）胜，将死 | 白（opus）胜，将死 |
| 总半回合 | 85（opus 43 步，sol 42 步） | 95（opus 48 步，sol 47 步） |
| 非法着 / 重选 | 双方都 0 次，每步第一次就给出合法着 | 同左 |
| 被拦、空回复、调用失败、撞额度、续跑 | 都没有 | 都没有 |
| 工具调用 | 0（sol 会话记录逐条查过，opus 由 llm-chat 零工具） | 0 |
| 大失误 opus / sol | 4 / 7 | 1 / 2 |
| 失误 opus / sol | 7 / 8 | 0 / 3 |
| 每步平均亏损（厘兵）opus / sol | 99.7 / 119.3 | 23.0 / 44.5 |
| 墙钟耗时 | 约 68 分钟（23:22–00:30） | 约 21 分钟（23:22–23:43） |
| opus 花费（标价，订阅不另收） | $5.17 | $0.92 |
| sol 用量 | 输入 11.7 万 + 缓存读 216 万，输出 9.85 万（其中思考 9.80 万） | 输入 7.5 万 + 缓存读 65 万，输出 1.91 万（其中思考 1.85 万） |

**思考量与每步耗时（中位数）**：中国象棋 opus 每步思考 2386 token、28 秒，sol 1862 token、44 秒；国际象棋 opus 只有 143 token、6 秒，sol 306 token、16 秒。opus 在国际象棋里 48 步中有 12 步完全没思考、30 步不到 200 token，sol 17 步不到 200。**opus xhigh 在整盘会话里想得很少**：第二批 xhigh 无状态整盘每步思考中位在 5700–10000 token 上下，新协议这两盘低了一到两个数量级（effort 已核实传到 claude -p）。原因没查：可能是连续会话、提示变短、局面简单几种因素叠加。它会影响「调高思考深度最管用」那条结论在新协议下还成不成立，值得单独看。

## 典型昏招

### 中国象棋（开局中炮对屏风马）

- **opus 5. 车九平八（亏 446）**：车出到 b 线，自己的炮还在 b2，黑炮 b7 隔着红炮就能打 b0 的车，等于白送一车。引擎首选车二进四。
- **sol 5… 炮２进２（亏 446）**：对手刚送的车没吃，引擎首选炮２进７打车。双方同一处漏看，恰好抵消。
- **sol 13… 马５退３（亏 801）**：马从 e8 退走，把第 8 条横线让开，红车可以从 c8 横到 g8 打马，局面从均势掉到大劣。
- **opus 14. 炮五进四（亏 582）**：没抓住上面这个机会，引擎首选车二进六。
- **sol 15… 炮６进１（亏 550）**：炮走到红马 d4 能吃到的 f5；**opus 16. 车二平三（亏 482）** 又没吃，引擎首选马六进四吃炮。sol 17… 炮８平９（亏 489）仍把那个炮留在马口，这次 opus 吃掉了。
- **sol 41… 车４平７（亏 381）**：残局贪吃一个兵，走完被 7 步杀。

这盘双方大多数大失误都是某个子能不能被吃到没看清，和第二批「多为漏看谁能吃到谁」的结论同一个样子。

### 国际象棋（西西里纳道夫型）

- **sol 17… Bxc4（亏 485）**：该用后吃回（Qxc4），用象吃把后留在 c7，白方有 18. Ra7 捉后、后只能换车。
- **opus 18. Ra4（亏 606）**：没看到 Ra7，把优势全还回去。
- **sol 19… Qxc3??（亏 713）**：后吃 c3 马，马有 b2 兵保护，bxc3 直接丢后，全盘由此崩掉。
- sol 25… g6（亏 123，已大劣）：引擎给出 5 步杀，之后 sol 在残局里几步王走位失误，opus 升后将死。

## 看得出和看不出的

- 看得出：新协议能跑通正式对局——连续会话、只给局面、不报将军，两盘都没有一次非法着、没有工具调用、没有调用故障，重选和判负机制这两盘根本没用上。
- 看不出：opus 和 sol 谁强。只有 2 盘、两盘都是 opus 先手，胜负和亏损都可能是偶然；中国象棋两边每步平均亏损都在 100 厘兵左右，是互送互漏的对局。
- 值得跟进：opus xhigh 在新协议下思考量大幅缩水（见上），若属实，新协议下的棋力可能比第二批的估计还低。
