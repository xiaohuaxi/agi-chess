# 整盘会话里思考量为什么少

## 一句话结论

**不是 bug：effort 两家都传到了，统计也没算错。opus 对 sol 国际象棋那盘思考量低，主要是两件事叠在一起：① 同一会话里接着下本身就想得少，同一局面只有新开会话的约四分之一；② 这盘从标准开局起步，前 26 个半回合是背熟的纳道夫定式，第 45 个半回合以后是一边倒的残局。** 新协议的提示只让思考少了一到两成。12 个局面里没看出「想得少」带来稳定的质量下降，只能看方向。

之前 `game-opus-vs-sol-1.md` 说「比第二批低了一到两个数量级」，是拿错了基准：5,700–10,000 是中国象棋 stateless 整盘的数。国际象棋 xhigh 整盘每步思考中位，stateless 是 1,265–1,432，session 是 710–809。

## 条件

- 对象：`runs/g1-c-opus-sol`（新协议、llm-chat、整盘一个会话，opus xhigh 执白、sol xhigh 执黑，95 个半回合，白胜）。实战每步思考中位 opus 143、sol 306。
- 对照实验：从这盘中局取局面，opus 取第 23/27/31/35/39/43 个半回合，sol 取第 24/28/32/36/40/44 个半回合，共 12 个局面，effort 都是 xhigh。每个局面跑四种条件：
  - **S 会话第 N 步**：复制实战会话记录、截到这一步之前、换 id 后续接，发实战原样的提示（核实过缓存读取、输入量和实战同一步一致，前文确实接上了）。
  - **R 新会话第一步**：新协议，走 llm-chat。
  - **Ro**：提示同 R，走旧调用路径（`claude -p` 直调 / 旧 `codex exec`）。
  - **L 旧协议 stateless**：旧提示（报将军、SAN 记录、要中文和简短思路），旧路径。
- S、R、L 各 2 遍，Ro 1 遍。质量用 Stockfish 19 深度 18 打分。花费：opus 真调 43 次，标价约 $2.1；sol 43 次。
- 原始材料只在本机临时目录，没入库（驱动脚本、每次调用的思考量与回答、引擎打分、抓到的请求体）。

## 每种怀疑的判定

| 怀疑 | 判定 | 证据 |
|---|---|---|
| effort 没传到 | 排除 | 用本机桩抓 llm-chat 发出的 Claude 请求，第一轮和续接轮都带 effort=xhigh、自适应思考、0 个工具，和旧路径 `claude -p` 的请求逐项一样；sol 的 codex 会话记录 47 轮全是 xhigh。R 对 Ro 分不开（opus 中位 1,756 对 1,443，sol 2,619 对 2,361），换调用路径不影响思考量。 |
| 统计算错 | 排除 | opus 每步思考量和 Claude 会话记录里每条回复的用量逐条对上，用时也吻合；sol「累计减上一轮」和 codex 每轮自报的单轮用量 47/47 一致。 |
| 新提示让它少想 | 影响小 | 同局面、新会话、同路径只换提示：opus 中位 1,963（旧）→ 1,756（新），sol 3,424 → 2,619，约一到两成。第六批局面题 opus 国际象棋也见过 2,054 → 1,544。 |
| 会话连续 | 主因 | 同局面同提示，会话第 N 步对新会话第一步：opus 中位 441 对 1,756，sol 874 对 2,619；按局面看 opus 6 个里 5 个更少，sol 6/6 更少。S 重现了实战的量级。第二批已见过同样现象（session 约为 stateless 的一半，随局数推进拉大）。 |
| 开局背谱、局面简单 | 主因之一 | 前 13 回合全是纳道夫 6.Be2 定式，opus 前 10 步思考中位 0；第二批整盘都先随机走 8 个半回合，没有这段背谱，两边不能直接比。按阶段对照，第 21–40 个半回合旧 stateless 1,723、旧 session 1,285、本盘 195；第 41–60 个半回合 1,822 / 1,007 / 473。本盘第 21–26 个半回合还在定式里。 |

旁证：同一套设置下的中国象棋那盘（`g1-x-opus-sol`），opus 每步思考中位 2,386、最多一步约 1.2 万，局面难时照样想得深。它对中国象棋 stateless 的 5,700–10,000 约低到四分之一到一半，和会话连续的幅度相当，但这盘没单独做对照。

## 想得少，下得更差了吗

平均亏损（厘兵）：opus S 35 / R 22 / Ro 27 / L 100，sol S 76 / R 22 / Ro 14 / L 56。亏损 ≥ 300 的只有 sol S 1 次（第 36 个半回合 c4b5，亏 693）、opus L 2 次。多数局面各条件走的是同一步。12 个局面、每格 6–12 次，**看不出会话里想得少带来稳定的质量损失**，和第二批块 C（session 约一半思考量，大失误率没显著差别）一致。

## 对后续的影响

- 「调高思考深度最管用」来自调 effort 档位，不等于每步思考 token 要多；整盘默认仍用 xhigh。
- 比思考量时，会话整盘只能和旧 session 整盘比，并且按阶段比，别拿 stateless 或局面题当基准。
- 从标准开局起步会有一段背谱、思考接近 0，拉低整盘统计，也让开局阶段没什么可比的。要避开，可以用预设的均势开局（待用户定，见 `status.md`）。

## 局限

- 只诊断了国际象棋一盘、12 个局面，只能看方向。
- 会话里少想，是模型复用了前几轮带过来的思考，还是前文全是一行着法让它「顺着」少想，这次分不开；要分开得在同一截断点做「去掉前文思考」的对照，Claude 那边直接问会被安全分类器拦（`design.md` P6），没做。
- 没测会话里调高到 max 能不能把思考量和质量拉回来。
