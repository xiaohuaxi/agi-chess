# opus 对 astra：中国象棋两盘，互换先后

## 一句话结论

**两盘都是 opus 将死 astra（执红 33 个半回合、执黑 52 个半回合），2 比 0；两盘都一口气下完，0 非法、0 重选、0 判负、0 续跑、0 工具调用。** 中国象棋上 astra 明显弱一截：opus 执黑那盘一个大失误都没有（每步平均亏损 31），astra 两盘都是在「谁能吃到谁」上丢子输棋。理由每步都写、都进了棋谱。**只有 2 盘，只能看方向。**

## 条件

第一盘短，大失误率的分母只有 9 步（开局一过就分出胜负），两边每步平均亏损都被那一两步大亏拉高，不必细比。

**每步思考与耗时（中位数，前一个数是 opus 执红那盘）**：opus 437 / 3,623 token，10.2 / 42.6 秒；astra 339 / 913 token，20.0 / 37.2 秒。opus 执黑那盘想得多得多（均值 4,491，最多一步 13,552），这盘也是它下得最干净的一盘；astra 最多一步 1,706。和国际象棋那两盘比（`game-opus-vs-astra-1.md`），astra 中国象棋每步想得多两三倍（国际象棋 110 / 217）。

**理由文字**：85 步全写、全中文，都进了 `record.txt` 每步评注。opus 中位 132 / 252 字（执黑那盘常分条列出对方的威胁和自己的应对），astra 中位 19 / 23 字，一句话说目的。

## 典型昏招

### opus 执红那盘（开局一过就定了）

- **opus 11. 车九平八（0→−432）**：理由写「和八路炮组成炮车组合，同时牵制对方 2 路炮」，没看到黑炮能隔着自己 b2 的炮打 b0 的车（引擎首选炮八进二，先把炮架挪开）。下一步 opus 自己在理由里才写出来：「对方的炮 b7 原本能借我炮 b2 当炮架打我 b0 的车」——**没看到**，典型的「谁能吃到谁」。
- **astra 12. 车１平２（+432→−1022）**：没吃那个白送的车，反而把车平到 b9，理由「占据开放纵线，与另一翼车马形成呼应」；红炮隔着黑炮直接打车。**双方同一处都没看到炮架关系**，和第一轮 Opus 对 Opus 的结论一个样子。之后 astra 一路丢子，第 33 个半回合被将死。
- 更早的 astra 6. 卒７进１（亏 338）、opus 7. 马八进七（又还回 338）也是一对互相漏看。

### astra 执红那盘

- **astra 37. 车五退二（−131→−445）**：理由「避开马袭，同时堵住黑马……并反攻黑马」，引擎首选车五平四；局面从小劣变成明显劣势。
- **astra 49. 相三进五（−373→−1284）**：黑车沿中路将军，astra 飞相去垫，理由「飞相挡住中路将军，保留车对红马的保护」；这个相没人保护，黑车直接吃相再将，两步后被将死。**又是没看到谁能吃到谁**。
- opus 这盘 0 个大失误，两个失误里最大的 46… 马６退４（亏 191），理由写了一大段「红马一来 f2 会同时捉车炮」的预防，是判断取舍，不是漏看。

## 看得出和看不出的

- 看得出：astra 当中国象棋棋手能顺畅下完（0 非法、0 工具调用、0 故障）；新的「一手棋最多 3 次」规矩这两盘没被触发。理由能直接定位错因：opus 11. 车九平八那句漏看在下一步自己的理由里被补出来。
- 看得出（方向）：中国象棋上 opus 强过 astra——2 比 0，astra 两盘都输在「谁能吃到谁」（炮架、无根子），opus 执黑那盘 0 大失误。国际象棋上两边分不开（`game-opus-vs-astra-1.md` 1 比 1），差别可能在中国象棋上。
- 看不出：差距有多大。只有 2 盘，其中一盘 33 个半回合就结束。
