# opus xhigh 对 astra max：国际象棋四盘，互换先后

## 一句话结论

**四盘 2 比 2：第一轮两盘都是执黑的一方将死，第二轮两盘都是执白的一方将死；opus 执白、执黑各赢 1 盘，astra 也一样。** 四盘都一口气下完，0 判负、0 续跑、0 工具调用、0 故障；非法着 5 次全是 opus 的（越子 4 次、目标格有己方子 1 次），都在第二次改对。把 astra 从 xhigh 调到 max，每步思考中位从 173 涨到 416 token、每步多等 7 秒多，但比分和 xhigh 一样看不出高下：这四盘双方每步平均亏损 opus 35.7 / astra 37.1，lichess 口径大失误 6 / 6。这四盘双方都比 xhigh 那六盘下得干净（xhigh 六盘 61.0 / 55.0），但 opus 这边同样是 xhigh、亏损也跟着降，说明更多是这几盘对局本身平稳，不能记到 astra 调高思考深度头上。**只有 4 盘，只看方向。**

xhigh 六盘里原来的四盘是 2 比 2，新补的两盘 astra 都赢了，见 `game-opus-vs-astra-1.md`。

读法：
- **max 想得多、等得久**：每步思考中位涨到 2.4 倍，每步多等约 7 秒，整盘思考量每步约是 xhigh 的 1.8 倍。
- **棋好没好分不出**：max 这四盘 astra 的亏损和大失误都比 xhigh 六盘低，但**同盘的 opus（一直是 xhigh）也低了同样多**（61.0→35.7，大失误每 100 步 7.2→2.5）。两边一起变干净，更像是这四盘碰巧平稳（两种开局各两盘，局面没有 xhigh 第三盘那种乱战），而不是 astra 变强。拿比分看，max 2 比 2，xhigh 4 比 2，也没有往 astra 这边倾斜。
- **非法着都在 opus 这边**：5 次全是走法没套对（车或象越子 4 次、马走到自己王的格子 1 次），都第二次改对；「一手最多 3 次」没被用满。
- **opus 花费**：四盘合计 $12.49，最高一盘 $4.01，离 $40 停止线很远。

## 典型昏招

### 盘 1（g3，opus 执白，astra max 胜）

- **opus 29. Bh3（胜率 58→36）**：理由在算黑马 h5 没路可走，没提黑方后翼的反击。随后 30…a4 打马，opus 第一次把马退到 c1——自己王站的格子，被判不合法；重选 **31. Na1（41→28）**，理由自己写「刚才没注意到我的王就在 c1」。非法之后的重选往往也不好。
- **opus 65. Nd4（38→9）**：理由把黑方的威胁（…Rf1 接 …Rxd1 杀）讲清楚了，选跳马挡长斜线；引擎首选 c5。**看见了威胁、应法判断错**。

### 盘 2（g3，astra max 执白，opus 胜）

- **astra 49. Qb4（45→9）**：理由「避开马的攻击，同时封住 b 兵推进」；opus 下一步 Rc4 把后的九个去处全封死，astra 只好弃后。**后走进没有退路的格子，没看到。** opus 这盘 0 大失误，是这批里最干净的一盘。

### 盘 3（g5，opus 执白，opus 胜）：两边各还一次大优势

- **astra 20… dxc5（46→27）**、**opus 21. Qd7（73→48）**：opus 理由写后打进 d7「同时攻击三个目标，d7 黑方没有子能吃到」，引擎首选 Bc4；这是算对了安全、没算对价值。
- **opus 23. Nd3（45→3）**：理由写「e7 被黑象控制，上一步想好的 Qe7 走不了」，把马调到 d3 守 b2、f2，并判断「就算 Qxa2+，王走 c2 也基本稳住」。**看到了对方的将军，判断错了后果**：黑后 a2 将军、c 兵冲上来，白方胜率只剩 3%。
- **astra 25… Rc8（96.7→6.5）**：astra 大优势下把车走到 c8，理由「把白后钉在王前」，但这个车没保护、白后沿 c 线直接吃掉。opus 下一步理由写「c5、c6、c7 都是空的，c8 车也没有保护……白吃一车」。**astra max 没看到车被白吃**，一步把赢棋还掉；之后 opus 一路赢下。

### 盘 4（g5，astra max 执白，astra 胜）

- **opus 22… Nc2（44→7）**：理由写马到 c2「同时攻击 e1 车和 e3 象，形成捉双，而且马有 c8 车保护」，打算对方 Bxc2 后 Rxc2 攻后。astra Bxc2 后，opus 下一步理由自己写「上一步是严重失误：我原以为 Rxc2 能攻击白后，但 c2 车没有保护，白后可以直接吃掉车」。**看到了交换、没算到最后一个吃子**。这是这盘 opus 唯一一件大失误，astra 0 大失误、每步平均亏损 14.5 平稳收下。

astra（不论 xhigh 还是 max）的理由都只有一句目的，大失误时看不出是没看到还是判断错；上面盘 3 的 Rc8 能从对手下一步的理由里反推出「车白给」。

## 看得出和看不出的

- 看得出：astra max 当棋手照样顺畅（四盘 0 非法、0 工具调用、0 故障），每步慢 7 秒左右，一盘一个钟头上下能下完。
- 看得出（方向）：astra 调到 max，想得多了、等得久了，比分仍是 2 比 2；亏损和大失误的下降对面的 opus 也同样有，归不到 max 头上。
- 看不出：max 对 astra 到底有没有用。要回答得在同一批局面上做局面题，比 max 和 xhigh 的选着，而不是靠 4 盘整盘。
- 看不出：opus 和 astra 在国际象棋上谁强。xhigh 六盘 astra 4 比 2，max 四盘 2 比 2，合起来十盘 astra 6 比 4，都在几盘偶然的范围内。
