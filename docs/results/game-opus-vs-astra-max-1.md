# opus xhigh 对 astra max：国际象棋两盘，互换先后

## 一句话结论

**又是 1 比 1，这回两盘都是执黑的一方将死对手（astra 执黑赢一盘，opus 执黑赢一盘）；两盘都一口气下完，没有续跑、没有工具调用、没有调用故障，非法 3 次全是 opus 的、都在第二次改对，没人被判负。** 把 astra 从 xhigh 调到 max，每步思考中位从一两百 token 涨到三百多，每步多花 5–6 秒，但下法质量看不出变好：每步平均亏损 49 / 35，和 xhigh 那两盘（52 / 37）几乎一样，lichess 口径大失误 4 次（xhigh 那两盘 6 次）。**只有 2 盘，只看方向。**

## 典型昏招

### opus 执白那盘（astra max 胜）

- **opus 29. Bh3（胜率 58→36）**：理由在算黑马 h5 没路可走、出象连车，没提黑方后翼的反击；引擎首选 Kb1 先把王挪开。下一步黑 a4 打马，opus 第一次想把马退到 c1——那是自己王站的格子，被判不合法；重选 **31. Na1（41→28）**，理由自己写「刚才没注意到我的王就在 c1」。和上一轮 56… Rc7+ 一样，**非法之后的重选往往也不好**。
- **opus 57. Rg4（42→28）**：又是非法后的重选（第一次车要越过自己 f3 的兵）。
- **opus 65. Nd4（38→9）**：理由把黑方的威胁（…Rf1 接 …Rxd1 杀）讲得很清楚，选了跳马挡长斜线；引擎首选 c5。**看见了威胁、应法判断错**，局面从小劣变成必败。
- astra max 也有 34… Rb8（74→54）、62… Rf2（87→62）两步把优势还回去一截，理由都是一句「占开放线施压」「车侵入第二横线」，但没影响结果。

### astra 执白那盘（opus 胜）

- **astra 49. Qb4（胜率 45→9）**：黑马 b3 打后，astra 把后走到 b4，理由「避开马的攻击，同时封住 b 兵推进，并向 d6 施压」；opus 下一步 Rc4，理由逐格列出白后九个去处全被封死，「至少要损失后换车」。astra 随即 Qxc4 弃后。**后走进了没有退路的格子，没看到。** 这是这盘唯一一件大失误，之后 opus 一路把优势兑现到将死。
- opus 这盘 0 大失误、0 失误，每步平均亏损 16.9，是目前整盘里最干净的一盘。

## 看得出和看不出的

- 看得出：astra max 当棋手照样顺畅（0 工具调用、0 非法、0 故障），每步慢 5–6 秒、整盘一个钟头以内能下完；新的「一手棋最多 3 次」这两盘没被用满。
- 看得出（方向）：astra 从 xhigh 调到 max，想得多了、等得久了，棋没有看得出的变好。要比 max 值不值，得在同一批局面上做局面题对比，而不是靠 2 盘整盘。
- 看不出：opus 和 astra 在国际象棋上谁强。加上 xhigh 那两盘，四盘 2 比 2，每盘都是赢家那方下得干净、输家那方有一两步大亏。
- 另一个样子：opus 三次非法都是「自己的子挡路 / 占格」这类读盘错，重选后的着法又两次掉分。只有 3 件，只能记一笔。
