# 第一批 A 块：思考深度对单步质量的影响（局面题）

- 日期：2026-09-26。条件：opus（服务端 `claude-opus-5-5`，Claude Code 2.1.282，`claude -p` 走订阅），stateless，每题只走一步，提示和整盘对局用的一样（默认视图、不给着法历史）。程序是 `agi_chess/quiz.py`（6f6ed45），判定口径写在它开头的注释里。
- 样本：两种棋各 30 个局面，medium / high / xhigh / max 四档，每档每局面答 2 遍，所以**每格 60 次作答**，一共 480 次。每格只有 30 个局面，下面的数字只能看方向，靠得住的只有配对检验单独点名的那几处。
- 原始数据都在 `runs/` 下，这个目录被 git 忽略、只在本机：总表 `runs/quiz-batch1/report.txt`，逐题判定 `runs/quiz-batch1/{xiangqi,chess}/judged.jsonl`，每次作答一个文件（提示、回复原文、用量）在同一目录。局面在 `data/batch1/{xiangqi,chess}.jsonl`（入库）。本文的补充统计用的是一次性脚本，没入库。

## 一句话结论

**思考越深，单步越少出昏招，这个方向在两种棋上都成立，最大的一跳在 high→xhigh（中国象棋）或 xhigh→max（国际象棋）；max 把静态判定的「谁能吃到谁」类昏招压到 0（读原文还剩一个中国象棋局面），但一次作答中位要 1.5–6.5 分钟、每次中位约 $0.2–0.8，而且剩下的错主要是找不到需要弃子或多步计算的战术。** medium 和 high 之间看不出差别。

## 配对检验：方向站不站得住

做法：同一局面在两档之间比错的次数（每档 0–2 次），数多少局面变好、变坏、不变。对变了的局面做双侧符号检验；另外按局面有放回重抽 1 万次，求「错误率平均降了多少」的 95% 区间。

| 棋种 / 指标 | 比较 | 变好 / 变坏 / 不变（局面数） | 符号检验 p | 错误率降幅（百分点）与 95% 区间 |
|---|---|---|---|---|
| 中国象棋 大失误 | medium→high | 2 / 3 / 25 | 1.0 | −1.7 [−11.7, 10.0] |
| | high→xhigh | 8 / 1 / 21 | 0.04 | 16.7 [5.0, 30.0] |
| | xhigh→max | 2 / 1 / 27 | 1.0 | 1.7 [−8.3, 11.7] |
| | medium→max | 8 / 1 / 21 | 0.04 | 16.7 [1.7, 31.7] |
| | high→max | 8 / 0 / 22 | 0.008 | 18.3 [8.3, 31.7] |
| 中国象棋 谁能吃到谁类 | high→xhigh | 8 / 1 / 21 | 0.04 | 13.3 [3.3, 23.3] |
| | xhigh→max | 6 / 0 / 24 | 0.03 | 13.3 [3.3, 25.0] |
| | medium→max | 11 / 0 / 19 | 0.001 | 30.0 [15.0, 45.0] |
| 国际象棋 没解中 | medium→high | 8 / 2 / 20 | 0.11 | 11.7 [1.7, 23.3] |
| | high→xhigh | 7 / 3 / 20 | 0.34 | 8.3 [−3.3, 20.0] |
| | xhigh→max | 10 / 1 / 19 | 0.01 | 15.0 [3.3, 26.7] |
| | medium→max | 15 / 0 / 15 | 0.00006 | 35.0 [21.7, 50.0] |

怎么读：
- **站得住的**：两种棋上 medium→max、high→max 都是一边倒（没有一个局面变坏），这是本批最硬的结论。中国象棋「谁能吃到谁类」从 medium 到 max 11 个局面变好、0 个变坏。
- **边缘**：相邻档里只有中国象棋 high→xhigh、国际象棋 xhigh→max 过了 0.05。一共比了十几对，这种 0.01–0.04 的 p 值当「很可能是真的」看，别当定论。
- **看不出差别**：medium 和 high 在中国象棋上几乎一样；中国象棋 xhigh→max 在大失误上已经贴地（3 次对 2 次），分不出来，但在谁能吃到谁类上还能看出降。

## 分项发现

**中国象棋：多数局面这次根本不再犯错。** 30 个局面里 19 个在四档、240 次作答里一次大失误都没出；错集中在 x05、x13–x16、x22、x25、x26 等 10 个局面。上一轮这些局面全被标成了昏招（大失误，或白送子 / 漏吃），这次同是 medium 只有 20% 大失误——局面是按「上一轮错过」挑的，再问一次自然会往回落（见「口径与局限」）。

**按上一轮的错因分类看**（局面数少，只看方向）：

| 上一轮类别 | 局面数 | 大失误 medium / high / xhigh / max | 谁能吃到谁类 medium / high / xhigh / max |
|---|---|---|---|
| 规则落到盘面错 | 14 | 25% / 18% / 11% / 0% | 39% / 32% / 18% / 0% |
| 看对但漏看 | 11 | 14% / 27% / 0% / 9% | 32% / 32% / 14% / 0% |
| 看对但判断错 | 3 | 全 0 | 全 0 |
| 无法判断 | 2 | 50% / 50% / 0% / 0% | 全 0 |

「规则落到盘面错」随档位一路降到 0；「看对但漏看」到 max 还剩 x05 那一个局面（两遍都错，见下）。

**又走出上一轮同一步的比例**：medium 28%（17/60）、high 28%、xhigh 12%（7/60）、max 7%（4/60）。max 那 4 次里有 2 次是 x05 的同一步昏招。

**国际象棋：按难度段和题型**

| 分组 | 局面数 | 解中率 medium / high / xhigh / max |
|---|---|---|
| rating 800–1199 | 10 | 75% / 90% / 90% / 100% |
| rating 1200–1599 | 10 | 45% / 45% / 50% / 80% |
| rating 1600–2000 | 10 | 40% / 60% / 80% / 85% |
| 杀棋题（mateIn1 / mateIn2） | 6 | 50% / 58% / 83% / 100% |
| 吃子战术题（其余 8 类） | 24 | 54% / 67% / 71% / 85% |

易题 medium 就解得差不多；中段题 max 才明显抬起来；难题从 high 开始逐档涨。题型里 attraction（引离、弃子引入）最难，max 也只有 2/6；c19（弃车引王 + 马双击，veryLong）四档 8 次全错。

**思考 token 和对错：只看方向。**
- 同一档内，中国象棋答错的想得更少（例如 medium 对 1,841 / 错 812，high 对 2,601 / 错 1,938）；同局面同档两遍一对一错时，错的那遍多数也是想得少的那遍（medium 3:1、high 4:1）。像是「匆匆拍板」出的错。
- 国际象棋正相反：答错的想得更多（max 对 8,214 / 错 101,556），同局面一对一错时错的那遍也多是想得多的（medium 7:1）。难题让它想得久，而且想久了未必想对。
- 所以「档位的收益就是想得多」只对了一半：跨档看，同一个局面上档位越高想得越多、越少错（同局面 max 的思考量是 medium 的 15–20 倍）；但在同一档里，思考量更多反映局面难不难，不能拿来预测对错。中国象棋 high 里思考量高的那一半（中位 5,023）错 17%，已经和 xhigh（中位 6,563）差不多思考量了，但 xhigh 只错 5%；国际象棋 high 里思考量高的一半反而错 47%。样本太小，分不清是「档位本身让它更仔细」还是「每档的思考量分布不同」。

**耗时与花费**：两种棋并发跑（各 4 路），中国象棋整批墙钟 3 小时 35 分，国际象棋 2 小时 21 分，max 占大头：中国象棋 max 60 次调用合计 8.3 小时，国际象棋 max 4.4 小时。max 单次最长 28 分钟（中国象棋 x10），13 次中国象棋、6 次国际象棋的 max 作答超过 15 分钟。

**英文作答**：约三分之一作答是英文（中文占比很低的那种）。中国象棋随档位上升：25% / 27% / 40% / 57%；国际象棋各档都在 30–35%。和对错的关系两种棋相反：中国象棋英文作答错得少一点（按档分层后差 −7 个百分点，同局面同档一中一英的格子里错数相等 4:4，所以大概率只是英文多出在 max）；国际象棋英文作答明显错得多（分层后 +26 个百分点，同局面同档一中一英、且一对一错的 10 个格子里 9 个是英文那遍错）。原因不清楚，只能说国际象棋上英文和答错一起出现，不能说是英文导致的。

## max / xhigh 残余昏招逐条归类

读回复原文和引擎续着后逐条判断。「谁能吃到谁」= 回复里对某子能不能吃到另一子说错了、或完全没提到一个现成的吃子关系。

| 局面 | 档 / 遍 | 走的 → 引擎首选 | 归类 | 依据 |
|---|---|---|---|---|
| 中 x05 | max r1、r2 | 车七进二 c5c7 → b7c7 | 谁能吃到谁（炮架） | 两遍都算「车换车后净赚一马」，没看见吃马后黑 a7 炮借红 b7 车当炮架直接打 c7 车；还说 c7 车能捉 a7 炮，其实被自己 b7 车挡着。和上一轮同一步、同一个盲点。 |
| 中 x16 | xhigh r1 | 车八退三 b3b0 → 相七进五 e2c0 | 谁能吃到谁（可达） | 断言「没有红子能走到 c0」，其实 e2 相能垫；又当成唯一应将，没检查吃炮后 a0 黑车直接吃回 b0。和上一轮同一步、同一句错话。 |
| 中 x26 | xhigh r1、r2 | 车二进六 h0h6 → 炮八进七 b2b9 | 谁能吃到谁（炮架） | 两遍都只看 h6 安不安全，没提 b2 炮可借 b7 黑炮当炮架打 b9 车（马吃回，净得车换炮）。上一轮在这个局面上是反过来的同一机制（没看见对方借 b2 炮打 b0）。 |
| 国 c12 | max r1 | Bg1+ → Bf4+ | 战术计算 | 读盘无错；没列出 Bf4+（同时将军并打 c7 车），又把 Kg3 之后的变化判成「不吃亏」，实际引擎看是和。 |
| 国 c16 | max r1 | Qxd6 → Qc3+ | 战术计算 | 对后、车、兵的攻防关系说得都对；没想到 Qc3+ 闪开 d 线让车打后。 |
| 国 c19 | max r1、r2 | Qh3 → Rh8+ | 战术计算 | 读盘无错，自己也说 Qh3 大概只能长将和；r1 算过 Rh8+ Kxh8 Qh3+ Qh6 Nxf7+ 双击，但判成「不清楚」。r2 耗时 26 分钟。 |
| 国 c26 | max r1 | Qxc4+ → cxd4 | 偏谁能吃到谁（两步内） | 以为 …Rxc4 之后还能 cxd4 吃马，没算到白车一离开 c 线、黑车就顺 c 线吃掉 c3 兵，威胁随之消失。 |
| 国 c29 | max r1 | Qc5 → Rxb7 | 战术计算 | 读盘基本对；漏了 …Rg8 配合黑后打 g2 的反击，还说「底线没有杀」。这题两遍都碰到 30 分钟超时后重试。 |
| 国 c29 | max r2 | Qxe5 → Rxb7 | 谁能吃到谁 | 靠「c6 马被 c1 车钉住」认为吃 e5 安全，想到了 …Qd1+ 引开，却没算 d3 黑后直接吃 b1 车（Rxb1 后钉子解除、马吃白后）。 |

小结：中国象棋 xhigh / max 的 5 条残余昏招全是「谁能吃到谁」，4 条是炮架、1 条是走子可达，而且 x05、x16 都是原样重犯上一轮。国际象棋 max 的 7 条里只有 1 条干净的谁能吃到谁（c29 r2）、1 条偏向这一类（c26），其余 5 条读盘都对，错在没找到弃子 / 闪击这类要主动去找的战术，或把续着判错。

## 口径与局限

- **样本少**：每格 60 次作答、30 个局面；同一局面的两遍不独立（配对检验按局面抽样就是为了这点）。所有比例只能看方向。
- **局面是挑过的，有偏**：中国象棋 30 个局面全是上一轮 opus（medium，整盘里）走出昏招的走前局面。这次 medium 大失误只有 20%，说明「挑犯过错的局面再问一次」会自然回落；不能把 20% 当成 opus medium 在普通局面上的昏招率，也不能拿它和上一轮「每 6 步丢一个子」直接比。国际象棋局面是 lichess 谜题（rating 800–2000，10 种题型各 3 题），每题都有一个明确正解，比普通对局局面「尖」得多：不解中基本就等于大失误，所以国际象棋的大失误率远高于中国象棋不说明它国际象棋更差。
- **单步题不等于整盘**：没有前后着法的连贯性、没有累积的疲劳或长历史，也没有时间压力；整盘里一步昏招会被后面的步放大或掩盖。
- **引擎判定**：中国象棋用 Fairy-Stockfish depth 16、国际象棋用 Stockfish 19 depth 18，分数截断 ±1000。中国象棋大失误 = 亏损 ≥ 250 厘兵、失误 100–249（沿用上一轮）；国际象棋按 lichess（胜率降 ≥ 15 / 10）。
- **国际象棋「失误」列全是 0**：谜题的设计就是只有一步能保住优势，走别的胜率至少降 15 个百分点，直接落到大失误，不会停在失误那一档。
- **上一轮的 WP30 口径和这次不同**：上一轮额外标了「胜率降 ≥ 30 个百分点」（WP30），这次国际象棋用 lichess 的 ≥ 15。用 WP30 重算这批：国际象棋和 lichess 口径完全一样（28 / 21 / 16 / 7 条，谜题错一步降得都远超 30）；中国象棋 WP30 是 7 / 10 / 2 / 2 条，和亏损 ≥ 250 的 12 / 13 / 3 / 2 条方向相同。
- **「谁能吃到谁类」是静态子力判定**，会漏（上面 x05 的例子）也会误报（弃子求杀会被标成白送子），所以只数同时被引擎判为失误以上的。
- **英文作答**：约三分之一回复是英文，提示是中文。没有强制语言，不影响判定（只看最后一行的着法），但读回复原文时要注意；国际象棋上英文和答错相关，原因未查。

## 异常

- **7 次调用碰到 30 分钟超时，全在 max 档**：中国象棋 x01 r1、x04 r1、x04 r2、x09 r2、x10 r2，国际象棋 c29 r1、c29 r2。每次都是第一次调用跑满 30 分钟被杀，30 秒后重试成功（重试那次用了 450–1,690 秒）。影响：记录里的用量和耗时只是重试那次的，被杀那次的思考和花费没有记录（合计少记约 3.5 小时调用时间；如果被杀前的输出也照常计费，按 max 大约每 30 分钟 $3 算，少记约 $20）；另外凡是想超过 30 分钟的作答都被换成了第二次尝试，max 的数据对「特别难、想特别久」的题有一点筛选。
- **4 次 max 作答在一次调用里跑了两轮**：输出超过单轮 128K 上限时 Claude Code 自己续了一轮，所以思考 token 最高到 15.4 万。不影响判定。
- **首答非法 4 次**（中国象棋 medium 2、high 1，国际象棋 medium 1），都在第二次给出合法着；无拦截、无空回复、无判负。

## 对后续实验的含义

- **整盘实验（组 2–4）用 xhigh 作默认档**：它拿到了从 high 往上的大部分收益（中国象棋大失误 22%→5%，谁能吃到谁类 27%→13%），每步中位 34–75 秒、约 $0.06–0.15，一盘 40 步模型着法大概 20–50 分钟。max 在单步上还更好（尤其国际象棋 73%→88%、中国象棋谁能吃到谁类降到 0），但中位 1.5–6.5 分钟一步、单步最长近 30 分钟，一盘整局要好几个小时，花费约是 xhigh 的 4–5 倍；只适合拿一两盘做「上限」对照，不适合当主力。medium 和 high 差别不大，要省就用 medium，别在两者之间多花一档。
- **做 max 就得放宽超时**：30 分钟上限在 max 上被撞了 7/120 次，整盘里被杀一次就白等 30 分钟。放宽到 45–60 分钟，或者超时后换低一档重答并记下来，两种办法选一个。
- **盲点是具体机制，可以有针对地测**：中国象棋剩下的错几乎全是炮架（隔一个子吃）和走子可达，而且同一局面会原样重犯。这正是思考延续（组 2、3）和「谁能吃到谁」清单这类做法该对准的地方，也可以把 x05、x16、x26 这类「深想也会错」的局面单独留着做回归题。
- **国际象棋谜题到 max 已经到顶**：易题段 max 100%，想再比档位或做法就得换更难的题（rating 2000 以上）或换成普通对局局面，否则分不开。
- **样本要扩就按局面扩**：同局面两遍往往一致（中国象棋 19 个、国际象棋 10 个局面八次全对，出错的局面也常是两遍一起错），多加局面比多加遍数值。
