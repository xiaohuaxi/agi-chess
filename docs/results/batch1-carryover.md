## 一句话结论

**思考确实能跨步带过去、模型也真用得上（对照实验证据很硬）；但带上以后，中国象棋里标志性的昏招——白丢车、漏看一两步杀——照样出现，三档大失误率看不出差别；国际象棋有带延续少犯大错的迹象，但件数只有个位数、还被开局路线搅在一起。所以「每步丢思考是下得臭的根源」这批数据不支持它是主因，最多是次要因素。** 盘数少、对手又是确定性的，这些都只能看方向。

其余都是默认值：附全部着法历史（`history=-1`）、不给合法着法清单、不开自查、不开复述、notes 只带最近 1 条便条、session 每步仍给完整局面、非法重试 3 次、200 个半回合上限。事后裁判：国际象棋 Stockfish 深度 18，中国象棋 Fairy-Stockfish 深度 16。

三档的差别（design.md 第三节）：stateless 每步新开、看不到自己之前的任何东西；notes 每步多写一段便条，原样放进下一步提示；session 每方一条连续会话，之前每一轮的思考和正文都在上下文里。三档系统提示只差一句：stateless 是「你看不到自己之前的思考和回答」，notes 是「每步回答里可以附一段便条…」，session 是「这是一段连续的对话，你前面几步的思考和回答都还在」。

## 对照实验：续接时模型用不用得上上一轮的思考

**用得上，证据强。** 做法是同一段会话复制两份，一份原样、一份只删掉上一轮那块看不见的思考，三路各续接一轮比行为（详见 `control/summary.md`）。

- **算过的中间结果**（37 个会话）：第一轮在思考里算出一个大数乘积、正文只回数字和，第二轮问乘积本身。第二轮思考 token 中位：原会话 117、原样副本 74、删思考副本 1130。**37/37 个会话都是删思考那组想得更多**，而且删思考组的思考量随题目难度一路涨（8 位 521 → 40 位 8594），保留组基本不涨，像是直接拿来用。正确率 37/37、37/37、35/37，删思考组错的两次都在 40 位档、重算时漏了一位数。
- **思考里做过的任意选择**（6 个会话，每臂分叉 3 次）：让它心里挑一个数再问 8 道是非题。3 次分叉答案完全一致的会话：原会话 6/6、原样副本 6/6、删思考副本 0/6。删思考组不说「我没挑」，而是每次现编一个数。
- **删的确实只有思考**：抓到的两份续接请求，拿掉思考块后只剩带会话 id 的那个字段不同；37/37 个会话里，原样副本比删思考副本第二轮多出的输入正好等于第一轮思考 token 数加 1。调用 213 次，拦截 0、报错 0。

**适用范围**：只测了隔几分钟、续接一轮。跨天续接（P8）、连续很多轮以后还用不用得上，没测。design.md 里 P5 那条「行为复测没定论」的缺口，这次补上了。

- 三档都约七成照上一步意图走，无故改各只有 1 例。stateless 的「延续」是同一个局面让它把同一个计划再推一遍，并不记得。

### session 档：长局后段、上下文和思考量

- **长局后段没看到明显变差**。真正下进后段（模型第 30 步以后）的 session 只有 2 盘：xq-session-1（78 步）和 ch-session-2（52 步）。正文长度没变短；用脚本把正文里「某格的某子」和实际棋盘比对，后段 198 处提及只有 2 处对不上，而且都是在说假设变化；大失误率后段也不比前段高（`metrics.md` 第三节）。这个检查只抓得住固定句式，漏检肯定有。

## 这批数据的局限

- **盘数太少**：国际象棋每档 3 盘、中国象棋每档 2 盘，大失误件数是个位数。
- **对手是确定性的，盘与盘不独立**：国际象棋 9 盘只走出 3 条开局路线，中国象棋 6 盘前 4 回合一样、同一个昏招出现 3 次。档位之间的差别和「落进哪条路线」分不开。
- **session 带的不只是思考**：它同时带着之前每一步的正文，系统提示也多告诉它一句「你前面几步的思考和回答都还在」。session 和 stateless 的差别不能全算到思考头上。
- **只测了 high**。局面题那一批（`batch1-depth.md`）显示 effort 从 high 升到 xhigh / max，单步昏招明显变少；换一档深度，延续的作用可能不一样。
- 思考原文拿不到（P4），「session 为什么想得少」「它用的是哪部分前文」只能从正文和用量间接推。
- 连贯打标是抽样、看正文，session 正文写得少，「无从判断」偏多。
- 对照实验只覆盖隔几分钟、续接一轮。

## 对「每步丢思考是下得臭的根源」意味着什么

- **前提成立**：思考确实跨轮带回去了，模型也确实拿来用（对照 37/37、6/6 对 0/6）。
- **但它不像是主因**：带上延续以后，中国象棋里最伤的那类错——没看见对方的子能吃到自己的车、没看见一两步之内的杀——照样发生，三档大失误率在 6–8% 之间晃；6 盘每盘都白丢车，和档位无关。这正是上一轮总结的「谁能吃到谁」问题，延续没把它压下去。
- 国际象棋有带延续少犯大错的迹象（5.9% → 2.8% / 1.8%，lichess 口径 3.9% → 2.5% / 1.1%），但太弱，而且 session 那一档的优势大半来自两盘白得后的短局。
- 所以这批数据**不支持**「丢思考是主因」，最多是次要因素；只能看方向。相比之下，局面题那一批里「想得更深」对单步昏招的作用要明显得多。

## 给下一批的建议

1. **让对手有随机性**，盘与盘才独立：开局前几步随机或走开局库，Maia 改成按策略概率抽样（或加温度），Fairy-Stockfish 也从随机开局出发。否则加盘数只是同一盘重下。
2. **盘数加到能区分的量**：按目前 3% 对 6% 这种差距粗估，每档至少要几百个未分胜负的步，也就是每档一二十盘，别再 2–3 盘。
3. **把 session 拆开**：加一档「stateless + 之前各步的完整正文」，和 session 比，才分得清是思考起作用还是正文起作用；系统提示那句多出来的话也要对齐。
4. **把力气转到「谁能吃到谁」**：昏招集中在看子、看杀，下一步该测针对它的做法，比如提示里列出双方被攻击、没保护的子，或者让它走之前自查「这步走完对方能吃什么、能不能将军」；比再加延续更可能见效。可以先在局面题上便宜地试。
5. **盯住 session 思考变少**：在中国象棋上比同一局面下 session 和 stateless 的思考量与对错，看是「复用」还是「偷懒」。
6. **系统提示补一句用中文回答**（两种棋都补）：stateless 换语言会妨碍读正文和做文本分析。
7. 延续还要继续测的话，effort 至少加一档 xhigh，看深度和延续叠加的效果。
