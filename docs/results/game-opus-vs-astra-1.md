# opus 对 astra 首轮：国际象棋两盘，互换先后

## 一句话结论

**两盘都是执白的一方将死对手（opus 执白赢一盘，astra 执白赢一盘），1 比 1；两盘都顺利下完，没有续跑、没有工具调用、没有调用故障，非法着一共 4 次、都在第一次重选就改对了。** 棋力看不出高下：两边每步平均亏损一盘 35 左右、一盘 51 左右，恰好各自执白那盘低；lichess 口径大失误 opus 5 次、astra 6 次。新加的「着法前写理由」每步都写了、都进了棋谱评注，但 opus 中位一百多字、残局常带列表和变化，astra 只写一句话。**只有 2 盘，只能看个样子。**

## 典型昏招

### opus 执白那盘

- **astra 19… Qa5（胜率 50→31）**、**21… Nc5（28→13）**：后和马都往白王那边压，理由写「保护侵入的车，制造将杀威胁」「增援对白王的围攻」，引擎首选是 Qa8、Kh8，把攻势先收住。
- **opus 22. Bxc5（87→59）**：理由写「黑马 c5 很危险，先用象换掉」，还列了三种吃回的变化；引擎首选 Bc4，换马把优势还回去一大半。**astra 22… Qxc5+（41→16）** 紧接着又没走引擎的 Rxf1。
- **opus 25. Rxd1（92→74）**：理由里明写考虑过王吃（Kxd1），认为「王到 d1 后黑方可以 Qg1+ 将军，接着吃掉 h1 的车」而放弃；引擎首选恰是 Kxd1。看见了、判断错，和第二批的结论同一个样子。
- 之后 astra 28… Bxg5 贪兵、33… h6 给了白方 8 步杀，opus 没走最快的杀（34. Rf1，理由是怕 c 线打开被长将），但仍在第 49 步将死。

### astra 执白那盘

- **opus 16… Ba6（胜率 49→10）**：理由写「a6 的象有 a8 车保护，是安全的」，引擎首选 Bd7；**astra 17. Ng3（90→56）** 没抓住，把优势还回去。双方同一处漏看，和对 sol 那两盘一样。
- **astra 30. Ng4、31. Re1、34. Nh2**（中局连着三步，胜率 47→29→16→8）：理由都是一句「反击 f6 弱兵」「守住中心兵」「撤开受攻击的马」，局面一步步交出去，opus 一度到 +9 兵。
- **opus 41… Bxb1（87→51）**：白马吃了黑方新升的后，opus 用象吃回，理由写「b1 的象有 a1 车保护，e1 车过来吃就会丢车」；引擎首选车吃（Rxb1），大优势一步还掉大半。
- **opus 56… Rc7+（40→3）**：这步是非法重选后的第二次回答（第一次 Rb2 被马挡住，理由里自己写了「b7 到 b2 这条线被 b5 的马挡住」），改走将军，结果进了必败局面，astra 在第 67 步将死。

## 看得出和看不出的

- 看得出：astra 当棋手能顺畅下完整盘（两盘 115 步，0 工具调用、0 故障、1 次非法），和 sol 一样可以接进来；「着法前写理由」不影响着法读取，理由都进了棋谱，而且写的内容能直接定位一部分昏招的错因（如 25. Rxd1、41… Bxb1 里「看见了、判断错」的那句）。
- 看不出：opus 和 astra 谁强。1 比 1、各自执白获胜，每步平均亏损也是各自执白那盘低，大失误 5 对 6；只有 2 盘，差别都在偶然范围内。
- 看不出：写理由有没有改变思考量或棋力——这次没有不写理由的对照，思考中位数比上一轮高也可能是对手和开局不同。
